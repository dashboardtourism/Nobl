# Туризм Нижегородской области

Интерактивный дашборд по туризму и средствам размещения Нижегородской области.

Страница — один самодостаточный файл `index.html`: все данные и код внутри, внешних библиотек, шрифтов и запросов нет. Работает и с GitHub Pages, и при открытии файла локально.

## Разделы и источники

| Раздел | Источник | Период |
|---|---|---|
| Размещённые, КСР, номерной фонд, места, ночёвки, загрузка, рейтинги регионов | Росстат | 2002–2025, помесячно 01.2022–07.2026 |
| Платные услуги населению | Росстат, оперативные данные | 2020–2025 |
| Муниципальный разрез и типы средств размещения | Нижегородстат | 2020–2025 |
| Количество туристических поездок, план и факт | ЕМИСС, показатель П1 Минэкономразвития | 2025–2026 |
| Турпоток: туристы и экскурсанты | Геоданные сотового оператора | 2025 к 2024 |
| Отели выборки: ADR, загрузка, RevPAR | Ассоциация гостеприимства Нижегородской области (АГНО) | 01.2024–06.2026 |
| Классифицированные средства размещения | Реестр гостеприимства, срез на 12.05.2026 | — |

Режим «Все визитёры» — сумма туристов и экскурсантов: совпадающие направления складываются, остальные входят в строку «Прочие».

## Публикация через GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в его корень файлы `index.html`, `README.md` и `.nojekyll` (Add file → Upload files → Commit changes).
2. Откройте Settings → Pages.
3. В блоке Build and deployment выберите Source: «Deploy from a branch», ветку `main` и папку `/ (root)`, нажмите Save.
4. Через 1–2 минуты дашборд откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Чтобы обновить данные, замените `index.html` новой версией и сделайте коммит — страница пересоберётся сама.

> Если репозиторий публичный, дашборд увидит любой. В разделе реестра есть контакты объектов размещения (телефоны, e-mail, ИНН) из открытого реестра гостеприимства.
